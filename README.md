# Mechyard Sandbox

A mobile-first 2D physics construction sandbox built for GitHub Pages and iOS browsers.

## Files
All project files are intentionally kept in the repository root. No folders are required.

## Run
Upload every file to the root of a GitHub repository and enable GitHub Pages, or open through any static web server.

The physics engine is Matter.js 0.20.0 loaded from jsDelivr. GitHub Pages or another web host is required; after a successful online load, the service worker caches the project and fetched assets for repeat visits.

## Controls
- Tap a build item, then tap the world to spawn it.
- Select tool: drag parts; drag empty space to pan.
- Pinch or mouse wheel: zoom.
- Hinge / Weld / Fixed Rope / Slider / Rope / Steel Rope / Spring: tap two objects.
- Activation: tap a button/timer/pressure pad, then a powered part.
- Tap a wired toggle button in Select mode to switch linked parts on/off.
- Freeze locks a body in place.
- No Collide toggles collision on an object.
- Workshop keeps Verity and Verity Monster featured and rotates three additional local mod listings every three hours.
- Save/Load uses local browser storage; Export/Import uses JSON build files.

## Included systems
Parts, armor, wheels, motor wheels, pistons, gyroscopes, thrusters, rotors, buttons, pressure pads, timers, gravity controls, colliders, freezing, rope, steel rope, springs, welds, hinges, wiring, ragdolls, magnets, lift cells, workshop mods, local saves, PWA support, sound effects, ambient music, and three sandbox maps.
